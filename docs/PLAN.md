# План доработки Zametnik

Рабочий план продукта. Исходные требования остаются в `docs/PRODUCT_SPEC.md`.  
Презентацию не делаем: доводим само приложение.

Решения, от которых отталкиваемся:

- Три цвета интерфейса: бумага, чернила, индиго. Радуга типов заметок уходит.
- Экран «Сегодня» — дела сверху и редактор дневной заметки снизу.
- Граф при открытии показывает всю сеть. Клик подсвечивает соседей. Повторный клик открывает текст. Быстрый двойной клик по-прежнему открывает доску карточек.
- Синхронизацию с сервером, Tauri и телефон не начинаем.

## 1. Цвет

Ровно три роли, без отдельных оттенков «задача / проект / человек / ошибка».

| Роль | Светлая тема | Тёмная тема | Где |
|---|---|---|---|
| Бумага | `#f8f9fc`, панели `#ffffff` | `#12131c`, панели `#1e1f2e` | фон, карточки, поля |
| Чернила | `#1a1b26`, вторичный `#5c6078` | `#eef0f6`, вторичный `#9498b0` | текст, рамки, второстепенные иконки |
| Индиго | `#5a7fd4` | `#7c9eff` | ссылки, кнопки, фокус, выбранный узел, активный пункт меню |

- Тип заметки показывается иконкой и подписью, не своим цветом.
- Связь `[[ ]]` — тонкая пунктирная линия индиго. Ручная стрелка на доске — та же линия, жирнее и со стрелкой.
- Просроченное и предупреждения — чернила и индиго, не розовый и не янтарный.
- Цвет из frontmatter и палитра из шести кружков на карточке не рисуются.
- Светлая и тёмная темы остаются. Меняется акцент и набор бумаги.

## 2. Заметки

Экран «Сегодня»: дата, события и задачи на сегодня, ниже редактор файла `ГГГГ-ММ-ДД`. Это тот же файл, что в списке заметок.

Список «Заметки» показывает дни, недели, проекты и задачи. Группы: Дни, Недели, Проекты, Задачи, остальное.

Связи:

- Справа от текста панель «Упоминается в».
- Клик по `[ ]` переключает задачу. `Ctrl+Enter` остаётся.
- `Ctrl+клик` берёт точку клика, а не старый курсор.
- Автодополнение `[[` обновляется, когда в хранилище появляется заметка.
- Переход по ссылке на дневную заметку открывает «Сегодня», на остальные — вкладку «Заметки».

Дальше по заметкам (ещё не в этом проходе):

- Кнопка хаба недели `Неделя N - YYYY`.
- Удаление заметки из списка и с карточки.
- Переименование файла и правка `[[старое имя]]` в других заметках.
- Идентификатор заметки — путь или uuid, чтобы два файла с одним именем в разных папках не затирали друг друга.
- Один парсер: сейчас логика продублирована в `src/lib/parser.ts` и `electron/vault.ts`.

## 3. Граф

- Стартовый вид — все заметки и все ссылки.
- Клик оставляет узел и соседей яркими, остальное приглушает.
- Повторный клик по уже выбранному узлу открывает текст.
- Двойной клик за короткое время открывает доску карточек.
- Ссылка на несуществующую заметку — пунктир. Клик по такому узлу создаёт заметку.
- Фильтры «Задачи», «Проекты», «Неделя» применяются к этому графу. «Неделя» оставляет хаб текущей недели, его дни и то, на что дни ссылаются.
- Подписи приглушённых узлов не рисуются, пока пользователь не приблизит граф. После успокоения физики кадры останавливаются.
- Позиции узлов запоминаются и не сбрасываются при сохранении текста.
- Доска карточек — тот же набор связей, не вторая база. Цвет стрелок тот же индиго.

## 4. Скорость

Сейчас набор текста через 800 мс сохраняет файл и заново читает весь vault.

- Сохранение одной заметки обновляет только её запись в индексе и пересобирает связи из уже прочитанных метаданных.
- Полный обход папки — при старте и когда открываем другое хранилище, не на каждый абзац.
- Журнал синхронизации не пишется на каждое сохранение текста.
- Напоминания не должны пересоздавать интервал на каждое изменение списка задач (ещё впереди).
- Внешние правки `.md` подхватывать по явной кнопке обновления (ещё впереди).

## 5. Остальное, без новых функций

- Крестик окна не прячет приложение в пустой трей. Иконка трея — PNG.
- Напоминание приходит и если срок прошёл, пока приложение спало.
- Настройка «открывать день при запуске» реально решает, создавать ли daily сразу.
- Повторное создание демо не затирает существующие файлы.
- Первый запуск спрашивает папку.

## Порядок

1. Палитра.
2. «Сегодня» с редактором дня, список с днями, клик по чекбоксу, переход по ссылке, панель упоминаний.
3. Полный граф с подсветкой соседей.
4. Сохранение без полного перечитывания vault.
5. Имена файлов, коллизии, удаление, хаб недели, напоминания, трей.

## Сделано в коде

- Палитра сведена к бумаге, чернилам и индиго: убраны цветные кружки карточек и стрелок, розовые и янтарные пометки.
- «Сегодня» показывает дела сверху и редактор дневной заметки снизу, справа список «Упоминается в».
- В списке заметок видны дни, недели, проекты и задачи.
- Чекбокс в тексте переключается кликом. `Ctrl+клик` берёт точку клика. Автодополнение `[[` обновляется без пересоздания редактора.
- Граф рисует всю сеть, клик подсвечивает соседей, повторный клик открывает текст, фильтр «Неделя» оставляет хаб и связанные дни.
- Сохранение заметки больше не перечитывает все файлы vault и не пишет журнал синхронизации на каждый абзац.

## Не сделано

Имена файлов при переименовании, коллизии одинаковых имён, удаление заметки, кнопка хаба недели, напоминания после сна, трей, единый парсер Electron и браузера. Это шаг 5.
